# Как подключить клиента — пошагово (проверено вживую на реальном аккаунте)

## Шаг 1. Добавить организацию/магазин
1. В левом меню открыть «Мои организации».
2. Нажать кнопку «Добавить организацию» — доступна ТОЛЬКО если куплена подписка или активирован демо-доступ. На аккаунте без тарифа этой кнопки на экране нет вообще (важно для отработки возражения «а покажите сначала»).
3. Заполнить поля:
   - «Название» — свободный текст (название кампании/кабинета).
   - «Маркетплейс» — выбор из списка: Wildberries / Ozon / Yandex Market.
   - «API ключ» — вставить ключ маркетплейса (см. инструкцию ниже).
   - Кнопка «Проверить» — проверяет валидность ключа.
   - Чекбокс «Индивидуальные условия» — для нестандартных случаев.
4. Кнопка «Создать» — завершает подключение.

## Как клиенту получить API-ключ Wildberries (дословная инструкция из интерфейса)
1. Открыть WB Seller → Настройки → Доступ к API.
2. Нажать «Создать новый токен».
3. Выбрать тип: Персональный токен или Сервисный токен.
4. Включить ВСЕ разрешения (галочки на все пункты).
5. Скопировать токен и вставить в поле API-ключа в MarketAI24.

**Важно для презентации безопасности:** доступ, который запрашивает платформа — ТОЛЬКО НА ЧТЕНИЕ. Изменения в кабинет клиента платформа вносить не может. Это снимает большинство возражений про безопасность данных.

## Реальные вопросы клиентов на этом этапе (из звонков)
- «Как это можно закинуть на наш кабинет, ничего не сломается?» → доступ только на чтение, без права вносить изменения.
- «Как подключить, если ноутбук не работает / я с телефона?» → для полноценного подключения и демонстрации нужен компьютер (для шаринга экрана), но сама интеграция по токену не требует камеры/микрофона.
- «Сколько ждать данные после подключения?» → первый импорт может занять до суток, дальше — обычно быстрее, зависит от скорости отдачи данных со стороны Wildberries.
- «Можно ли несколько кабинетов?» → да, разные звонки называют разный лимит (2, 4 — вероятно зависит от тарифа), уточнять текущий лимит перед звонком.

## Дальнейшие шаги после подключения (по документации)
1. На дашборде появляются: финансовый отчёт, «Рука на пульсе», ДДС — данные подтягиваются автоматически.
2. Зайти в «Юнит-экономику», выгрузить шаблон, заполнить себестоимость товаров вручную — без этого клиент видит оборот, но НЕ видит реальную прибыль. Это важно проговаривать сразу, иначе клиент решит, что «отчёты не работают».

## Демо-доступ
- 48 часов, полный функционал, 0 ₽ по официальным условиям.
- ⚠️ На практике на проверенном аккаунте демо было с привязкой карты и автосписанием после 48 часов (см. файл про тарифы) — уточнять текущую механику активации у РОПа, не обещать однозначно «без карты».
- В одном из звонков клиент получал демо через верификацию карты на 10 ₽ с возвратом.

## Типичные технические вопросы на первом звонке
- **«Можно ли интегрировать с 1С / Bitrix?»** — с Bitrix да (задачи приходят с параметрами по артикулам, графики не передаются, можно слать ссылки на аналитику). Про 1С в звонке подтверждали возможность, но детали не обсуждались подробно — не завышать ожидания без уточнения.
- **«Поддерживаются ли другие маркетплейсы кроме Wildberries?»** — на момент звонков платформа была заточена под Wildberries, Ozon в разработке/добавляется поэтапно. Уточнять актуальный статус.
- **«Как часто обновляются данные?»** — в разных звонках: «раз в час», «данные тянутся в течение дня», «финотчёт с задержкой до 2 недель для самых точных цифр (по которым идут выплаты)». Общая логика: воронка продаж — быстрые приблизительные данные, финансовый отчёт — точнее, но с задержкой.
